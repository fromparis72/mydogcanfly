titre. Je le retiens quand même, parce que la note est déclarative : quelqu'un
l'a écrite pour dire ce qu'il avait fait. L'ignorer serait une fausse mesure dans
l'autre sens — prétendre que rien n'a jamais été vérifié. Le prédicat est isolé
dans trois constantes nommées (`VERIFICATION_REELLE`, `AVEU_NON_VERIFIE`,
`IMPORT_DE_SOI`) : si vous jugez le signal insuffisant, il se durcit en un seul
endroit, et les 60 tombent à 0 sans rien casser d'autre.

4. RÉEMPLOI EXACT DES TYPES ET STATUTS EXISTANTS — AUCUN NOUVEAU MODÈLE
──────────────────────────────────────────────────────────────────────────────
Vos quatre classes existent déjà dans le dépôt. Rien n'est à créer.

  `verified_official`
      = `T0bAuditSource` (packages/knowledge/src/t0b-migration.ts:115)
      = `SourcedQuote` + locator OBLIGATOIRE + cadence de 90 jours exacte.
      `SourcedQuote` (packages/knowledge/src/breed-restrictions.ts:533) impose
      déjà : citation ≥ 10 caractères, `quote_language` BCP-47, URL http(s),
      refus de l'auto-citation MyDogCanFly, types de source factuels,
      `review_due` ≥ `verified_date`.
      → strictement plus exigeant que ce que je vous avais proposé. Je maintiens
        la correction : j'avais écrit que le modèle de preuve « ne pouvait pas
        porter ce qui allait lui être demandé ». C'était faux.

  `corroborated`
      = `Source` (packages/knowledge/src/common.ts:119), le modèle général :
      URL, `source_type`, `verified_date`, `review_due`, `confidence` 1–5,
      `reviewer`, `history`. Une source officielle SANS citation verbatim.
      → aucun champ nouveau. La distinction entre les deux classes est
        STRUCTURELLE : la présence de `quote` fait la différence, elle n'est pas
        déclarée dans un drapeau qui pourrait mentir.

  `legacy_unverified`
      = `review_state: "legacy_unreviewed"` (objects.ts:202), projeté par
      `projectPlacementPolicy` en `status: "confirmation_required"` +
      `status_cause: "legacy_unreviewed"` (objects.ts:231).
      → déjà porté par 84 blocs, déjà rendu, déjà traduit en quatre langues.

  `unknown`
      = absence de bloc. Le schéma d'ingestion refuse déjà un canal visible dont
      `policies:` ne décide pas (ingest-airlines.mjs:216) : la classe est
      inconstructible, et c'est bien ainsi.

UNE SEULE DÉVIATION, ARGUMENTÉE, SOUMISE À ARBITRAGE
Vous demandez de réemployer `legacy_unreviewed` pour tout ce qui est rétrogradé.
Je ne peux pas le faire pour les 60 CORROBORÉS, et la raison est mécanique :
`preuve.ts:estNonRevue()` renvoie `null` sur toute politique dont la cause est
`legacy_unreviewed` — délibérément, car c'est le correctif d'une faute réelle
(dix politiques non revues portaient une source officielle et auraient été
présentées comme auditées). Si je réemploie ce littéral pour les corroborés,
`preuveAuditee` masque leur source, et l'indication prudente n'a plus rien à
montrer : elle redevient un silence.

Je propose donc UNE valeur de plus dans l'énumération EXISTANTE `status_cause` :
`"source_corroborated"`. Pas un modèle, pas un sous-système : une quatrième
valeur dans un enum de trois, sur la seule branche qui porte déjà une cause.
`preuve.ts` n'est pas touché. Si vous refusez cette valeur, le repli est le
scénario A — 216 rétrogradations muettes — et je l'appliquerai sans discuter.
